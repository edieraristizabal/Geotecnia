# Geotecnia para geólogos

Material del curso de Geotecnia para estudiantes de Ingeniería Geológica, Universidad Nacional de Colombia, sede Medellín.

Todo el contenido fuente está en la rama `main`. Un GitHub Action construye la página (Jekyll) y el libro (Jupyter Book) y los publica en la rama `gh-pages`. Ver `CLAUDE.md` para la estructura y el flujo de actualización.
